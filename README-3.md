# Facility Asset Condition Tracker

Excel workbook for reviewing building asset condition, repair priorities and capital project milestones.
**All data and facility names are fictional sample data.** Built with AI assistance.

![Dashboard](dashboard.png)

## Features
- 48 assets across six facilities and 30 projects
- Facility Condition Index (repair cost / replacement value)
- Priority flags and late or over-budget milestone flags
- Dashboard with KPIs, charts and top 10 high priority repairs
- PivotTable of repair cost by facility and component, filtered by priority
- Data validation and conditional formatting
- Optional VBA macro to export the dashboard to PDF

## Files
- `Facility_Asset_Condition_Tracker.xlsx`
- `Asset_Findings_Report.pdf`
- `ExportAssetDashboard.bas`

## Assumptions
Priority thresholds and service lives are illustrative, not an official standard. They can be edited on the Lookups sheet.
The findings report is a snapshot dated 2026-11-25.
